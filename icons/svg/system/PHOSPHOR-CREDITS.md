# Phosphor-derived file glyphs

Source: https://github.com/phosphor-icons/core (npm `@phosphor-icons/core` 2.1.1), Regular weight stroke sources (`raw/regular`), https://phosphoricons.com/?q=file

Redrawn onto the DS 16x16 grid (coordinates scaled 1.1x about the centre, stroke 1.5, round caps and joins, ink #4A4A4A), matching `system-file-xls`.

Glyphs (36): system-file-archive, system-file-c, system-file-cloud, system-file-code, system-file-cpp, system-file-c-sharp, system-file-css, system-file-csv, system-file-dashed, system-file-doc, system-file-html, system-file-image, system-file-ini, system-file-jpg, system-file-js, system-file-jsx, system-file-lock, system-file-magnifying-glass, system-file-md, system-file-minus, system-file-pdf, system-file-plus, system-file-png, system-file-ppt, system-file-py, system-file-rs, system-file-sql, system-file-svg, system-file-text, system-file-ts, system-file-tsx, system-file-txt, system-file-video, system-file-vue, system-file-x, system-file-zip

Not derived from Phosphor (kept as drawn in Figma): system-file, system-files, system-file-arrow-down, system-file-arrow-up, system-file-audio, system-file-xls.
