<aha-loader> fills its container on a white ground and centres the animated AhaSlides splash: eight brand dots gather, the petals bloom with a quarter-turn, hold, then close one by one. Make the container full-screen for a real environment transition; size the logo with --aha-loader-size (default 112px). It is decorative brand motion, not a progress bar: pass a present-tense label (announced via role="status"), never a percentage. Under prefers-reduced-motion it shows the finished logo, still. logo-only shows the finished logo alone, with no dot ring, for short or inline loads; it opens on the logo, so a load that ends in a moment never shows dots. The splash plays on separate layers that the browser moves itself, so it keeps playing while an app's startup code keeps the page busy; the petals cross-fade into the finished logo as they open. engine="svg" restores the previous renderer, which melts the petals together but stops whenever the page is busy. variant="tiles" keeps the previous five-tile look; <html data-aha-loader="tiles"> switches every loader on the page at once. For an inline indeterminate wait inside an existing surface, reach for Spin → instead.
