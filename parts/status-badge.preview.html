App-supplied colours (not design system styles)
The design system gives status no hue, so it ships no green, red or amber style and this page draws none. An app that already owns an approved result colour set (Report: Correct, Partially correct, Incorrect) keeps its colours and takes only the box, by setting two custom properties once in its own stylesheet:
.report-result--correct aha-status-badge { --aha-status-badge-bg: var(--report-correct-bg); --aha-status-badge-fg: var(--report-correct-fg) }
Then <aha-status-badge look="quiet" icon="system-check">Correct</aha-status-badge> renders in the same 28px box with the app's colours. Never use the two properties on a lifecycle, progress or due state.
